# 动画分镜规范：LeetCode 560 和为 K 的子数组

## 目标与算法状态

交互样例限制为最多 8 个整数；超过规模的输入会提示并拒绝，避免一次遍历分镜超过 40 帧。三种演示均使用预先生成、不可变的步骤快照；播放器只按索引回放，不在 UI 中重新执行算法。可观察状态包括输入数组、当前连续区间、累计和、哈希解法的前缀和频次表、已命中答案、当前操作、关键变量和代码锚点。

## 统一坐标与身份

逻辑画布按 1200×720 比例响应式扩展。数组槽位固定为 `array-{index}`，最多 8 项时沿水平主轴居中，中心点按 `x = originX + index * 92`、`y = 175` 计算；输入变化时重新居中，同一输入跨帧位置不变。哈希槽位固定为 `hash-{prefixSum}`，位于下方独立泳道，按首次出现顺序分配固定槽位，已有项跨帧 ID 和坐标保持不变。答案区使用区间语义 ID `answer-{start}-{end}`。

## 解法步骤与教学焦点

| 解法 | 每个可见动作 | 焦点/锚点 | 说明 |
| --- | --- | --- | --- |
| 暴力枚举 O(n²) | 初始化；每个左端点保留首个候选作为区间起点，并逐个命中帧记录有效区间；完成 | 区间节点最多两个 `compare`，命中转 `done`；`brute-init`, `brute-extend`, `brute-match`, `brute-done` | 每个候选区间恰好一帧，保持连续区间的枚举顺序。 |
| 前缀和 O(n²) | 初始化前缀数组；每个连续区间单独比较；命中帧记录区间；完成 | 边界前缀最多两个 `compare`，命中区间转 `done`；`prefix-init`, `prefix-compare`, `prefix-match`, `prefix-done` | 对每个非空连续区间展示 `prefix[right+1] - prefix[left]`。 |
| 前缀和 + 哈希表 O(n) | 初始化 `{0:1}`；读取当前值并累加；查询 `sum-k`；命中记录区间；插入/增加当前前缀频次；完成 | 当前数组节点单焦点，命中目标哈希卡片短暂 `done`，插入只突出新增键；`hash-init`, `hash-read`, `hash-query`, `hash-match`, `hash-insert`, `hash-done` | 查询和插入分开成帧，严格先查询、后插入，正确处理零与负前缀和。 |

每帧有唯一 `operation`、完整句子 `narration`、稳定 `anchorIds`、变量旁注、稳定 ID 的完整画布快照、固定图例和快照指标。当前焦点离开后留作 `visited`；答案为 `done`。连续帧复用同一个槽位坐标，哈希表项按稳定 key 只增不乱序。

## 状态、图例与动效

固定图例顺序：当前、比较、已访问、命中、未处理。颜色使用全局 UI 色彩规范的青绿/琥珀/石板色板，不使用紫色；状态同时由文字/边框/形状标记，不仅依赖颜色。motion token：入场 220ms、移动 360ms、退场 180ms、状态 240ms、箭头 420ms、答案强调 360ms；停留时间 1000ms，实际更新时长不超过停留的 45%，根据播放倍率同步缩放。换帧先中断当前命名过渡，退出通过 transition end 后移除。

`prefers-reduced-motion: reduce` 时所有 JS 动画时长与 CSS 动效置零，快照、解说、图例、代码锚点照常更新。镜头由单次初始化确定；切帧不重置平移缩放。

## 验证范围

覆盖三个算法结果及帧契约、前进/回退/再前进确定性、稳定节点 ID/坐标、当前焦点上限、代码锚点、命中区间正确性。真实页面检查 1366×768 / 1920×1080，1x/3x 播放、跳步与 reduced-motion。
