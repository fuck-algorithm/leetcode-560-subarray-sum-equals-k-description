# 动画分镜规范：LeetCode 560 和为 K 的子数组

## 目标与算法状态

交互样例限制为最多 8 个整数；超过规模的输入会提示并拒绝，避免一次遍历分镜超过 40 帧。三种演示均使用预先生成、不可变的步骤快照；播放器只按索引回放，不在 UI 中重新执行算法。可观察状态包括输入数组、当前连续区间、累计和、哈希解法的前缀和频次表、已命中答案、当前操作、关键变量和代码锚点。

## 统一坐标与身份

逻辑画布基准为 1200×720；SVG 在窄视口扩展 viewBox，不缩小中心内容。数组槽位固定为 `array-{index}`，按 `x = 600 + (index - (n - 1)/2) * min(220, 1040/max(n-1,1))`、`y = 250` 计算（单元素居中），节点 72×48。前缀边界位于 `y=360`，按当前可见边界数单独居中，节点 92×48。哈希槽位固定为 `hash-{prefixSum}`，位于 `y=412+row*54` 的下方网格，四列、列距 112，固定槽位及 `0` 哨兵常驻，最多 8 项时所有卡片位于 `y≤628`；已有 key 跨帧 ID/坐标不变。节点坐标均指中心点，矩形按宽高定位。答案区间用 `answer-{start}-{end}` ID，在各自起始数组元素下方的 4 条稳定结果轨道展示。

## 解法步骤与教学焦点

| 解法 | 每个可见动作 | 焦点/锚点 | 说明 |
| --- | --- | --- | --- |
| 暴力枚举 O(n²) | 初始化；每个左端点保留首个候选作为区间起点，并逐个命中帧记录有效区间；完成 | 区间节点最多两个 `compare`，命中转 `done`；`brute-init`, `brute-extend`, `brute-match`, `brute-done` | 每个候选区间恰好一帧，保持连续区间的枚举顺序。 |
| 前缀和 O(n²) | 初始化前缀数组；每个连续区间单独比较；命中帧记录区间；完成 | 每个比较帧只将 `P[left]` 与 `P[right+1]` 两个边界标成 `compare`；数据焦点上限为 2 | 对每个非空连续区间展示 `prefix[right+1] - prefix[left]`。 |
| 前缀和 + 哈希表 O(n) | 初始化 `{0:1}`；读取当前值并累加；查询 `sum-k`；命中记录区间；插入/增加当前前缀频次；完成 | 当前数组节点单焦点，命中目标哈希卡片短暂 `done`，插入只突出新增键；`hash-init`, `hash-read`, `hash-query`, `hash-match`, `hash-insert`, `hash-done` | 查询和插入分开成帧，严格先查询、后插入，正确处理零与负前缀和。 |

每帧有唯一 `operation`、完整句子 `narration`、稳定 `anchorIds`、变量旁注、稳定 ID 的完整画布快照、固定图例和快照指标。当前焦点离开后留作 `visited`；答案为 `done`。连续帧复用同一个槽位坐标，哈希表项按稳定 key 只增不乱序。

## 状态、图例与动效

固定图例顺序：当前、比较、已访问、命中、未处理。颜色使用青绿/琥珀/石板色板，不使用紫色；状态同时由描边和文本传达。算法画布不再播放入场、弹性、移动或描线动画；切步仅更新静态快照和节点状态，避免动效干扰因果关系。数据箭头使用显式三次贝塞尔圆角折线路由（路由通道本身不带额外弧线）：从当前数组节点下边缘留 8px 开始，沿竖向短引线进入水平通道，再从目标频次卡上边缘留 8px 接入；同一行时采用短直连。箭头只用于“查询/写回”等有数据流语义的步骤，初始化状态直接显示 `0 × 1`，不画装饰箭头。箭头标签放在横向通道正上方，距箭线至少 8px，且不与目标卡片标签同一高度。

`prefers-reduced-motion: reduce` 时所有 JS 动画时长与 CSS 动效置零，快照、解说、图例、代码锚点照常更新。镜头由单次初始化确定；切帧不重置平移缩放。
