# 动画分镜规范：LeetCode 560 和为 K 的子数组

## 目标与算法状态

交互样例限制为最多 8 个整数；超过规模的输入会提示并拒绝，避免一次遍历分镜超过 40 帧。三种演示均使用预先生成、不可变的步骤快照；播放器只按索引回放，不在 UI 中重新执行算法。可观察状态包括输入数组、当前连续区间、累计和、哈希解法的前缀和频次表、已命中答案、当前操作、关键变量和代码锚点。

## 统一坐标与身份

逻辑画布基准为 1200×720；SVG 根据容器宽高比扩展 viewBox，并在首次测得容器尺寸时计算一次 fit camera；后续 resize 只更新数据坐标域，保留用户拖拽/缩放变换。宽屏内容沿主轴展开，窄视口仍保留节点间最小间距。数组槽位固定为 `array-{index}`，按 `x = 600 + (index - (n - 1)/2) * min(220, 1040/max(n-1,1))`、`y=250` 计算（单元素居中），节点 72×48。前缀边界位于 `y=360`，按可见边界数单独居中，节点 92×48。哈希槽位固定为 `hash-{prefixSum}`，按首次出现顺序放入 `x=600+(column-1)*112`、`y=412+row*54` 的三列网格；`0` 哨兵持续可见，已有 key 跨步 ID/坐标稳定。节点坐标指矩形中心。答案区间以稳定 `answer-{start}-{end}` ID 放在相关主结构下方的四条固定结果轨道。节点坐标均指中心点，矩形按宽高定位。答案区间用 `answer-{start}-{end}` ID，在各自起始数组元素下方的 4 条稳定结果轨道展示。

## 解法步骤与教学焦点

| 解法 | 每个可见动作 | 焦点/锚点 | 说明 |
| --- | --- | --- | --- |
| 暴力枚举 O(n²) | 初始化；每个左端点保留首个候选作为区间起点，并逐个命中帧记录有效区间；完成 | 区间节点最多两个 `compare`，命中转 `done`；`brute-init`, `brute-extend`, `brute-match`, `brute-done` | 每个候选区间恰好一帧，保持连续区间的枚举顺序。 |
| 前缀和 O(n²) | 初始化前缀数组；每个连续区间单独比较；命中帧记录区间；完成 | 每个比较帧只将 `P[left]` 与 `P[right+1]` 两个边界标成 `compare`；数据焦点上限为 2 | 对每个非空连续区间展示 `prefix[right+1] - prefix[left]`。 |
| 前缀和 + 哈希表 O(n) | 初始化 `{0:1}`；读取当前值并累加；查询 `sum-k`；命中记录区间；插入/增加当前前缀频次；完成 | 当前数组节点单焦点，命中目标哈希卡片短暂 `done`，插入只突出新增键；`hash-init`, `hash-read`, `hash-query`, `hash-match`, `hash-insert`, `hash-done` | 查询和插入分开成帧，严格先查询、后插入，正确处理零与负前缀和。 |

每帧有唯一 `operation`、完整句子 `narration`、稳定 `anchorIds`、变量旁注、稳定 ID 的完整画布快照、固定图例和快照指标。当前焦点离开后留作 `visited`；答案为 `done`。连续帧复用同一个槽位坐标，哈希表项按稳定 key 只增不乱序。

## 状态、图例与动效

固定图例顺序：当前、比较、已访问、命中、未处理。颜色使用青绿/琥珀/石板色板，不使用紫色；状态同时由描边和文本传达。算法画布不再播放入场、弹性、移动或描线动画；切步仅更新静态快照和节点状态，避免动效干扰因果关系。箭头路径必须由稳定的 `fromId/toId` 定义关系；渲染时从当前帧节点矩形边缘求实际端点，不将快照旧坐标作为绘制依据。箭头 route helper 统一返回本帧 path geometry 和弧长标签锚点，避免两套独立公式。lookup/insert 只在算法确有数据流关系时绘制；哨兵初始化不画箭头，标签避开节点和值说明。

`prefers-reduced-motion: reduce` 时所有 JS 动画时长与 CSS 动效置零，快照、解说、图例、代码锚点照常更新。镜头由单次初始化确定；切帧不重置平移缩放。

## 验证范围

覆盖三个算法结果及帧契约、前进/回退/再前进确定性、稳定节点 ID/坐标、当前焦点上限、代码锚点、命中区间正确性。真实页面检查 1366×768 / 1920×1080，1x/3x 播放、跳步与 reduced-motion。
