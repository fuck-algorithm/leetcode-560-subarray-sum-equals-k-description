## 算法说明

### 1. 暴力解法 O(n²)

枚举所有可能的子数组，计算每个子数组的和并与 k 比较。

**优点**：实现简单，空间复杂度 O(1)  
**缺点**：时间复杂度高，不适合大数据集

### 2. 前缀和解法 O(n²)

先计算前缀和数组，然后通过前缀和差值快速计算子数组和。

**优点**：优化了子数组和的计算  
**缺点**：仍需双重循环枚举所有子数组

### 3. 前缀和+哈希表解法 O(n)（推荐）

利用哈希表记录前缀和出现的次数，单次遍历即可找到所有符合条件的子数组。

**核心思想**：  
对于当前前缀和 `current_sum`，如果存在之前的前缀和 `prev_sum` 使得  
`current_sum - prev_sum = k`，则找到一个符合条件的子数组。

通过哈希表查询 `current_sum - k` 的出现次数，即可得到以当前位置为结尾的所有符合条件的子数组数量。

**优点**：时间复杂度最优，工业级实现  
**缺点**：需要 O(n) 额外空间
